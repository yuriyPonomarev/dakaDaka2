## Loop and requirements

Equal class kit -> choose loot versus fighting/avoiding human or bot parties -> improve gear while surviving shrinking safe zone -> descend floors -> secure final escape/bank earned loot -> stash and next base-kit match. Zone/timer/remaining parties, hit feedback, loot and explicit outcomes make choices readable. Loot/time/position are competing resources; success depends on player decisions.

Server owns zone damage, roster, elimination, portals and winner. Offline uses the same rules. Bots use normal movement/combat/item authority and real corpses; existing monsters remain. Fill opposition when humans absent: a sole human must not win instantly. Reconnect cannot revive eliminated actors. Preserve item UIDs/affixes/ammo; bank once, no stash carry-in advantage or profile reset. Exact original timings/counts remain unverified and must be explicit configurable project tuning.
