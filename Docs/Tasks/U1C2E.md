**How it samples:** `RunKey` builds one probe per command after validation, calls `Seed()` **before** `QueueKeyboard(keys, true)` (records `positionStart`, `minMoveDistance`, and whether the review key was already down), calls `Sample()` after every `yield return null` in **both** the `seconds` do/while and the `frames` for-loop, then `QueueKeyboard(keys, false)`, one frame, `FinishProbe()` (records `positionEnd`/`displacement`) and passes the object to the existing `Finish`. Nothing is static or cached between commands: a fresh probe per id, so an ack can only describe its own frames. Trace is bounded to 6 evenly spaced entries (`hold/6` frames, or `seconds/6` of real time), never one per frame; no new action, no per-frame file write, no screenshot added to key acks (judged not cheap: it would insert `WaitForEndOfFrame` into the hold).
