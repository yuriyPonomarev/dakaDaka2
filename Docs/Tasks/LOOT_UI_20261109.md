# LOOT-01 — paired inventory and loot

User request: own inventory left; chest/enemy contents right; dead player equipment and bag in the same layout as own. Reference supplied in chat. Date: 9 November 2026.

## Implementation

- Existing inventory selection/equip/use/drop/hotbar command model retained. Shared paper-doll geometry, bag footprints, original cached silhouette icons, rarity borders, readable value/free-space footer and existing item tooltips. No imported art or new packages.
- Corpse server model retains source bag coordinates, equipment slots and dimensions. Wire schema2 / protocol7 prevents old clients joining with an incompatible layout/protocol.
- Network chests roll once, hand custody to the container registry and open an owner-only window. Opening does not collect anything. Reopening shares the same items; sealed-chest admission remains checked on state/transfer requests.
- Enemy drops enter the same server registry through the existing death drop callback. Failure to admit a container preserves the old floor-pickup fallback instead of losing rolled items.
- Transfers reuse the existing server revision/range/LOS/UID/profile checks. Click transfers a stack; Shift+click one unit. Failed transfers leave the source intact. Own bag remains usable alongside loot. Empty containers stay visible until closed.
- Escape/I close both panes; input focus prevents the same key reopening the bag or toggling pause in that frame. Client HUD uses a narrow status strip above the inventory.
