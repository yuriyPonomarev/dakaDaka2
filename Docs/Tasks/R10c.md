# R10c — central affix-key routing

## Status

Accepted after root source review and Unity verification on 24 October 2026.

## Changes

- Added one typed affix route table for all 13 existing `AffixStatKey` ordinals in `Runtime/Data/AffixVocabulary.cs`. The route values distinguish attributes, flat `SkillStat` destinations, and flat melee/projectile weapon-base channels. `IsAttribute` and `TryAsAttribute` delegate to this table, and unknown numeric casts fail.
- Updated `Equipment.AddRolledNumericAffixes`, `EffectiveStatsResolver.SumFlatDamage`, and PlayerRig’s unready flat-damage fallback to read route metadata. Equipment fixed modifiers, the once-only attribute path, flat damage channels, multipliers, ordering, and sanitization remain separate.
- Added `Editor/EmberdelveAffixRouteGate.cs` with independent route expectations for ordinals 0–12, rejection of cast 99, and valid catalog-backed attribute and damage consumer checks.
