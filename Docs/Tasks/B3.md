Backlog (D1b): "StaminaComponent and derived stamina data are dead weight: remove in a later cleanup with the gates that assert them." Nothing was compiled or run (no Unity here). Two root steps, because saved scenes carry the component.

## Scene / prefab strategy (what was found)
- The player rig is built only by `EmberdelveLevelBuilder.BuildPlayer` (`StaminaComponent.Ensure(rigGo)` plus `SetReference(rig, "stamina", ...)`). `LobbyBuilder` has no rig. There are NO player prefabs (no `SaveAsPrefabAsset` in the Editor code).
- `EmberdelveAssetLibrary.BuildAll` (what every smoke gate runs) only writes materials and ScriptableObject data. It does NOT regenerate `Emberdelve_Level01.unity` or `Lobby.unity`. Only the menu `Emberdelve/Build Vertical Slice (all)` (and the Level/Lobby-only entries) rebuild scenes.
- `R8aSavedSerializationGate` opens the SAVED scenes and fails on any missing MonoBehaviour. So deleting the script first would break it. Hence Step A (strip from saved scenes while the script still exists) and then Step B (delete).
- Alternative to the cleanup tool, equivalent: run `Emberdelve/Build Vertical Slice (all)` in Step A and save. The cleanup tool is preferred because it changes nothing else in the scenes.

## Step A (files in current/, root applies, then runs the cleanup)
All code references to `StaminaComponent` are removed; `Runtime/Combat/StaminaComponent.cs` is deliberately still present (nothing uses it).
1. Copy current/ over the project. Let Unity compile (the script `StaminaComponent.cs` still compiles on its own).
2. Run `Emberdelve/B3 Strip StaminaComponent` (or batch `-executeMethod Emberdelve.EditorTools.EmberdelveStaminaCleanup.Run`). It opens Lobby and Level01, removes every component whose type name is `StaminaComponent` (by name, so it also works after the script is gone), saves the scene only if something was removed, does the same for every prefab under Assets, and logs `[Emberdelve][B3Cleanup] DONE removed=N assetsRewritten=M missingScriptsStillInScenes=K`. Expected: removed=1 (Level01 rig), K=0.
3. Commit the changed .unity files. Optionally re-run `R8aSavedSerializationGate` here (still passes).
