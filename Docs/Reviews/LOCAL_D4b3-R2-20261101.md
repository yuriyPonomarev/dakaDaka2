(line 153, next to the pre-existing `manaRegenDelay = 1000`) and the harness applies a real nonlethal

`_timeSinceDamage = 0` (line 75). Before the wound `IsRegenerating` is true (rate 2 > 0, clock 1000 ≥ delay 1000);
